凌雾跨设备传输 —— 使用说明（v1.3 · 双向）
（手机 ⇄ 电脑 · 局域网直连 · 不经过任何服务器）
================================================================

两个文件：
  凌雾跨设备传输.exe   电脑端（免安装，双击就能用）
  凌雾跨设备传输.apk   手机端安装包（v1.3，versionCode 4）


零、v1.3 修了什么（对照你反馈的两点）
----------------------------------------------------------------
问题一：「手动填 IP 和配对码能连上，但搜索/深度搜索都搜不到电脑」
  根因不是代码写错了，是**网络结构**：

      光猫 / 主路由  192.168.1.1
        ├── 电脑（网线）      192.168.1.6      ← 电脑在这个网段
        └── 小米路由器 192.168.31.1（WAN 接在主路由上）
              └── 手机（WiFi）  192.168.31.x   ← 手机在另一个网段

  · 手机→电脑能连，是因为这是"往外走"的流量，经小米路由器 NAT 后能到达电脑。
  · 广播（255.255.255.255 或 192.168.31.255）出不了自己的网段，电脑永远收不到。
  · 旧版「深度搜索」只扫手机自己所在的 192.168.31.1-254，电脑在 192.168.1.x，自然扫不到。

  v1.3 改法：搜索不再只靠广播，改成**广播 + 跨网段单播探测**
  （对自己网段 + 192.168.1/192.168.0/192.168.2/192.168.31/10.0.0/10.0.1 这些常见网段逐个单播）。
  单播能穿过 NAT，所以现在能自动找到跨网段的电脑。

问题二：「要记住连过的设备，下次一点就连」
  v1.3 新增「已连接过的设备」历史：
  · 每次**真正连成功**（测试连接/发文件/接收模式）都会记一条：电脑名 + IP + 配对码 + 上次使用时间
  · 下次打开 App，**先静默试连上次那台**：连上就直接显示「已连上上次的电脑：Marco」
  · 点历史里的设备 = 自动填好地址和配对码并立刻试连，**不用再输 IP**
  · 如果电脑那边换了配对码：会提示「配对码不对」，清空输入框等你填新的，填完再点测试即连上
  · 长按历史设备 = 从列表里删除（最多保留 8 台）


一、电脑端
----------------------------------------------------------------
双击「凌雾跨设备传输.exe」即可，不需要安装。
· 点 × 进托盘后台；右键托盘可：显示主界面 / 发送文件到手机 / 暂停或继续接收 /
  打开接收文件夹 / 修复网络放行 / 退出
· 接收目录默认：D:\0.Marco Work Space 工作合集\手机传入\传入区（手机→电脑的落点）
· 界面四块：①接收状态+配对码+地址 ②接收目录 ③发送到手机 ④传输记录（收/发）


二、手机端安装（覆盖安装即可）
----------------------------------------------------------------
apk 传进手机（数据线 / 放到「手机传入\传入区」用文件管理器装 / 微信发送），
MIUI 提示未知来源时：设置 → 应用设置 → 应用管理 → ⋮ → 安装未知应用 → 允许文件管理器。
覆盖安装会保留历史设备和设置。


三、最快用法（第二次起）
----------------------------------------------------------------
打开手机 App → 它会自动连上次的电脑（显示「已连上上次的电脑：Marco」）
→ 直接点「① 选择图片/视频」→「② 发送到电脑」。
不用点头搜索、不用输 IP、不用输配对码。


四、手机 → 电脑 / 电脑 → 手机
----------------------------------------------------------------
手机→电脑：手机选文件 →「发送到电脑」→ 落在电脑「接收目录」
电脑→手机：手机点「进入接收模式」→ 电脑那行变绿「已就绪：你的机型（IP）」
           → 电脑上点「选择文件发送到手机」或**直接把文件拖进窗口**
           → 手机「下载/凌雾传输」里出现文件，两边都有进度条


五、搜不到 / 连不上时
----------------------------------------------------------------
1. 先看有没有历史设备，点它试；或点「重新搜索」（现在含跨网段探测，约 4 秒）。
2. 还不行点「深度搜索」（跨网段探测 + 本网段端口扫描）。
3. 最稳的一招：把电脑窗口上的 IP 和配对码填进手机，点「测试连接」——
   这条一直在你机器上验证有效。
4. 「测试连接」的四种结果分别对应：
     配对成功            → 一切正常
     配对码不对          → 填电脑上现在显示的 6 位（电脑点「换一个」会变）
     电脑已暂停          → 去电脑把开关打开
     连不上              → 电脑程序没跑 / IP 变了 / 不在同一网络
5. 想让"广播搜索"也立刻生效，可以把手机连到**主路由（192.168.1.x）的 WiFi**，
   和电脑同网段；不过 v1.3 跨网段也能搜到了，不换也行。
6. 电脑端还有问题：右键托盘「修复网络放行」；最后可把 exe 旁边 data\diag.log
   最后几行发我（里面有：收到的发现请求、TCP 连接、接收模式、放行结果）。


六、安全
----------------------------------------------------------------
· 不走云，同一局域网 TCP 直连 · 配对码保护（两个方向都要）
· 防火墙只放行本机网段 · 只存不执行 · 开关一点即暂停 · 手机端不对外开端口


七、已知限制
----------------------------------------------------------------
· 手机端要留在前台（接收模式也是），被系统挂起会断开，重点一次即可
· 一次只服务一个接收模式连接
· 同名文件不覆盖（电脑端「名字 (2).xxx」，手机端系统自动改名）
· 传输记录只保留本次运行（最多 200 行）
· 跨网段搜索依赖"手机能往外访问电脑"，如果路由器开了"访客网络隔离"就仍需手动 IP


八、卸载
----------------------------------------------------------------
电脑端：托盘退出，删程序和旁边 data 文件夹
        （要清防火墙规则：netsh advfirewall firewall delete rule name="凌雾传输 TCP"
          和 name="凌雾传输 发现"）
手机端：长按图标卸载；收到的文件在「下载/凌雾传输」自行删除


九、技术参数
----------------------------------------------------------------
· 协议：自定义二进制 TCP v1（v1.3 扩展，兼容旧客户端）
    帧类型 1=文件 2=一批结束 3=手机申请接收模式 5=接收回执
· 握手回执：OK|<电脑名>（手机据此显示并记住设备）
· 端口：TCP 51888（占用自动 +1 到 51899）；UDP 51889 发现
· 发现：同网段广播 + 跨网段单播（自己的网段 + 常见网段），单播可穿 NAT
· 深度搜索兜底：对本网段 1-254 的 51888 发空配对码握手，回 0/1/2 即认定本程序
· 电脑端收文件：先写 .lwpart_ 临时文件，收完改名，避免半截文件
· 电脑端发文件：每发完一个文件等手机回执，失败即中止并提示
· 手机端：minSdk 24（Android 7+），targetSdk 34，无第三方库
    存「下载/凌雾传输」：Android 10+ 走 MediaStore（无需权限），更早版本需一次存储权限
· 电脑端：单文件 .NET WinForms，无需安装 .NET
· 诊断：程序目录 data\diag.log
